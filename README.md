# STEM Made Simple

**STEM Made Simple** is an interactive educational website designed to make STEM concepts easier to understand for middle school learners.

## Features

- **Three STEM topics:** Coding, Electricity, and Math.
- **Interactive lessons:** Learn concepts through approachable explanations and examples.
- **Knowledge-check quizzes:** Test your understanding of each topic.
- **Instant feedback:** Receive quiz results and completion messages.
- **Learning resources:** Explore additional resources through lesson source links.
- **My Progress dashboard:** Track completed quizzes and review scores.
- **Saved progress:** Quiz results are stored locally in the browser.
- **Light and dark themes:** Switch between visual themes.

## Technologies Used

- HTML5
- CSS
- JavaScript
- Browser Local Storage

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension for local development.

## Future Improvements

- Store a history of multiple quiz attempts.
- Add more STEM topics and lessons.
- Continue improving mobile usability and accessibility.

## Purpose

The goal of STEM Made Simple is to make STEM learning more approachable, interactive, and encouraging for students who are beginning to explore these subjects.
