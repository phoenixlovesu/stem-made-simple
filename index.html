CODING FUNDAMENTALS

Teach your code to think.

Programs can repeat actions and make decisions based on what happens.

01

Loops

Repeat instructions instead of writing them over and over.

EXAMPLE REPEAT 4 TIMES 
  move_forward()
02

Conditionals

Choose what to do based on whether something is true.

EXAMPLE IF obstacle_ahead 
  turn_right()
✦

Think about it this way

A loop is like replaying your favorite song. A conditional is like taking an umbrella if it rains.
